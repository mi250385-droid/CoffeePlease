Snowglobe

Because looking at a normal webpage wasn't whimsical enough for me.

Welcome to My beautiful Snowglobe, which is a small interactive webpage designed to spit out kind messages everytime you click on the button.

This project uses HTML, CSS and JavaScript to create an interactive snowglobe that you can shake. Yes. Shake it. We humans have evolved beyond just simply staring at pictures.

What is this?

An interactive digital snowglobe.

The goal for this website was to make the experience feel calm and magical, rather than like a school website assembled at 11:39 pm. This is your go-to website for a little motivation after a long day!

How to use it:

Please note that you can directly use the Demo Link to view the website.

Demo link: https://mi250385-droid.github.io/CoffeePlease/

Link to repository: https://github.com/mi250385-droid/CoffeePlease

Steps after cloning  or downloading the repository:

1. Open the project. 
Make sure that all the files are kept together.
The image should also be in the same folder as it's to be used by the website.

2. Now open index.html in your browser.
Congratulations! You have successfully summoned the snowglobe of gratitude.

3. Admire it.
You should be able to see: title, tagline, snowglobe, button (press for message), and footer.

   Very organised. Unlike my browser tabs.

4. Shake the globe.
By clicking the button, Javascript runs bts to add the shaking class to the globe. Which then CSS uses to activate the animation to make it move.

And boom! The globe shakes, you get a nice message, everyone's happy.

Languages used:

HTML- Website Framework.

CSS- styling and the animation.

CSS gradients- soft background and globe effects.

CSS animations- the shaking effects.

JavaScript- for interaction.

responsive resizing- this is so it could adapt to different screen sizing.
